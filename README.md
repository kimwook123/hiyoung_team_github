# (주)하이버스 연계 프로젝트 / 팀 하이영 작업내용
미래내일 일경험 프로젝트 : 산업 안전을 위한 영상 데이터에서 이벤트 탐지 및 알람 가능한 AI 모니터링 서비스 구현 프로젝트

. 프로젝트 개요
  가. 추진배경 및 필요성
   ㅇ 제안 기업인 ㈜하이버스는 산업용 디스플레이, 임베디드 시스템, 키오스트 하드웨어를 함께 제공할 수 있는 역량을 보유하고 있음. 제안 기업이 보유한 하드웨어와 시스템 역량을 기반으로 기존 제품군에 다양한 응용서비스를 탑재하여 사업의 다각화를 시도하고 있음
   ㅇ 제안 기업이 보유하고 있는 하드웨어에 산업 안전 관련된 서비스 탑재의 필요성이 증대하고 있음
      - 중대재해처벌법 등 산업 안전 규제가 강화되면서, 기존 감시 시스템의 한계를 넘어 작업자의 안전모 미착용과 같은 위험 상황을 즉각적으로 인지하고 알람을 줄 수 있는 실시간 모니터링시스템 수요 급증함
      - 단순한 영상 녹화를 넘어 수집된 영상 데이터를 기반으로 사각지대 없이 위험 상황이나 이상 패턴을 즉각적으로 인지하고 대처할 수 있는 실시간 AI 분석 시스템이 필수적으로 요구되는 시점임
      - 제안 기업의 임베디드 시스템이나 키오스크에 영상 AI 기술을 탑재하면, 산업 현장에 즉각적으로 설치하여 자율 감시가 가능한 지능형 엣지디바이스로 상용화할 수 있어 성공적인 사업 다각화를 이룰 수 있음

  나. 프로젝트 소개
   ㅇ 본 프로젝트는 영상 데이터를 분석하여 산업 현장의 안전을 확보할 수 있는 AI 기술과 모니터링 대시보드를 개발하는 것을 목표로 함
      - 실시간 영상 이벤트 탐지 AI 모델 개발: 영상에서 작업자를 인식하고, 안전모 미착용 등의 위험 상황 패턴을 실시간으로 학습하고 분류하는 인공지능 모델 개발함
      - 영상 데이터 전처리 및 탐색적 데이터 분석: 영상에서 정상적인 작업 환경과 탐지하고자 하는 이상 상황(안전모 미착용, 위험 구역 침입/배회 등)을 명확히 분리할 수 있는 기술 개발함
      - 지능형 대시보드(웹 또는 앱) 서비스 구현: 개발된 AI 모델을 바탕으로 관리자가 직관적으로 상황을 파악할 수 있도록, 이상 이벤트 감지 시 즉각적으로 알림을 전송하고 이벤트 로그를 보여주는 서비스 구축함
   ㅇ 개발된 결과물은 제안 기업의 제품 개발을 위한 프로토타입으로 활용하여, 개발 기간 단축과 테스트베드로 활용할 수 있음
      - 프로젝트의 결과물을 프로토타입으로 활용하여, 기능과 성능을 개선하여 제품화에 활용
      - 제안 기업에서 개발하는 기술의 테스트를 위한 도구로 활용할 수 있음
