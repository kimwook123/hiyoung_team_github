# Demo Checklist

## 1. 사전 확인

- [ ] Python 3.12 사용 가능 여부 확인
- [ ] `run_server.bat`로 서버 의존성 자동 설치 가능한지 확인
- [ ] `run_gui_only.bat`로 Flutter/Visual Studio/Windows SDK 자동 확인 흐름이 뜨는지 확인
- [ ] 테스트 영상 파일 준비 여부 확인
- [ ] `safety_monitor_server/app/analysis/models/weights/` 가중치 파일 존재 여부 확인

## 2. 서버 실행

- [ ] `run_server.bat` 실행
- [ ] `http://<서버IP>:8000/health` 응답 확인
- [ ] `GET /api/sources` 응답 확인
- [ ] 서버만 실행 중이어도 미완료 영상 소스가 이어서 분석되는지 확인

## 3. GUI 실행

- [ ] `run_gui_only.bat` 실행
- [ ] 서버 주소 입력/저장/재사용이 되는지 확인
- [ ] 영상 파일 선택 가능 여부 확인
- [ ] 스트림 등록 가능 여부 확인
- [ ] 서버 등록 소스를 `화면에 열기`로 다시 붙일 수 있는지 확인
- [ ] 선택된 소스 로그만 표시되는지 확인
- [ ] 선택 해제 시 전체 로그가 보이는지 확인

## 4. 분석 흐름

- [ ] 소스 등록 후 서버 `source_status`가 `starting -> running`으로 바뀌는지 확인
- [ ] 스트림/CCTV가 끊겼을 때 `reconnecting`으로 바뀌고 재시도하는지 확인
- [ ] 이벤트가 `events`에 저장되는지 확인
- [ ] 프레임 탐지 스냅샷이 저장되는지 확인
- [ ] 클립이 `data/clips/`에 생성되는지 확인
- [ ] 업로드 영상은 `data/uploaded_sources/`, 유튜브 캐시는 `data/source_cache/`에 저장되는지 확인

## 5. GUI 상호작용

- [ ] 이벤트 클릭 시 시작 시점으로 이동하는지 확인
- [ ] 클립 열기 후 원본 복귀 가능한지 확인
- [ ] 클립 닫기 버튼만 표시되고 소스 전환 상태에는 `클립 재생`이 안 보이는지 확인
- [ ] 다른 소스 전환 시 이전 영상이 pause되는지 확인
- [ ] 객체 탐지 박스가 현재 재생 시간 기준으로 갱신되는지 확인
- [ ] 진행도(`last_time / total duration`)가 현재 선택 소스와 서버 등록 소스에 표시되는지 확인

## 6. 멀티소스

- [ ] 소스 2개 이상 등록 시 둘 다 서버 상태가 갱신되는지 확인
- [ ] 활성 소스를 바꿔도 다른 소스 분석이 계속되는지 확인
- [ ] 소스 삭제 시 해당 소스 worker만 멈추는지 확인
- [ ] 서버 완전 삭제(관리자용) 시 이벤트/클립/업로드 원본 영상이 함께 지워지는지 확인
