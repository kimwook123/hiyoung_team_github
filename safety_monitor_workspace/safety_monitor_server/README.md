# Safety Monitor Server

서버는 중앙 저장소이자 이벤트 판정 서버입니다.

## 서버가 담당하는 일

- 등록 소스 메타데이터 저장
- 소스별 최신 상태 저장
- 프리뷰 이미지와 프리뷰 스트림 제공
- 프레임 탐지 결과 저장
- 소스별 `rule_config`를 읽어 이벤트 판정
- 이벤트 DB 저장
- 이벤트 클립 저장
- 뷰어/클라이언트용 조회 API와 실시간 업데이트 제공

## 서버가 하지 않는 일

- 로컬 영상 파일 직접 열기
- 로컬 카메라 직접 열기
- RTSP/스트림 원본 직접 소유
- YOLO 가중치 소유
- TensorRT 엔진 소유
- 클라이언트 대신 GPU 추론 실행

## 현재 구조에서 중요한 점

- 객체 탐지 자체는 클라이언트가 수행합니다.
- 이벤트 판정과 중앙 저장은 서버가 수행합니다.
- 뷰어는 서버만 바라봅니다.

## 실행

```powershell
cd safety_monitor_server
py -3.12 -m uvicorn main:app --host 0.0.0.0 --port 8000
```
